# Руководство пользователя «Учёт имущества школы»

Система учёта имущества школы работает с ПК (полный интерфейс) и со смартфона
(PWA: устанавливается на главный экран и может работать офлайн).

---

## 1. Вход в систему

1. Откройте адрес системы в браузере.
2. Введите **логин** и **пароль**, выданные администратором.
3. Нажмите «Войти».

Пароль можно сменить в профиле (раздел «Сменить пароль»). При утере пароля
обратитесь к администратору.

> **Установка на смартфон (PWA):** в браузере телефона (Chrome/Safari) откройте
> меню «Добавить на главный экран». Приложение установится как обычное и сможет
> открываться офлайн.

---

## 2. Роли и права

| Роль | Что может |
|------|-----------|
| **Завхоз / МОЛ** | создавать и редактировать карточки имущества, перемещения, списания, проводить инвентаризацию, вести ремонт/выдачу, выгружать отчёты |
| **Директор / зам.** | утверждать списания и перемещения, просматривать сводные отчёты и журнал аудита |
| **Муниципалитет / проверяющий** | только просмотр: карточки, отчёты, история изменений, выгрузки (без изменений) |
| **Администратор** | управление пользователями, ролями, справочниками, настройками нумерации |

> После утверждения акта или инвентаризации редактирование блокируется — это
> защищает целостность данных.

## 3. Работа с ПК

### 3.1. Структура учреждения
Раздел **«Помещения»**: создайте здания (корпуса) и кабинеты/помещения,
привяжите их друг к другу.

### 3.2. Справочники
Администратор ведёт типы объектов (оборудование, мебель, спорт и т.д.),
настраиваемые атрибуты карточек, состояния, единицы измерения, материалы.

### 3.3. Имущество (карточки)
- Раздел **«Имущество»** → кнопка **«Добавить»**.
- Укажите тип, наименование, модель, серийный номер, помещение, год, стоимость.
- Инвентарный номер присваивается автоматически по правилам нумерации либо
  вручную (флажок «свой номер»).
- Можно **загрузить фото** карточки.
- Доступен **поиск/фильтр** по номеру, типу, кабинету, статусу, серийному номеру.

### 3.4. Операции
Из карточки имущества доступны действия:
- **Переместить** — выбрать новое помещение и причину.
- **В ремонт** — указать подрядчика, описание, сроки, стоимость.
- **Выдать** — кому, на какой срок; при возврате фиксируется состояние.
- **Списать** — причина, комиссия; акт проходит согласование и утверждение.

### 3.5. Инвентаризация
1. Создайте инвентаризацию (тип, период, охват).
2. **Начать** — система сформирует опись по всем карточкам.
3. Отмечайте фактические позиции (см. также мобильный режим).
4. Завершите — система подсчитает расхождения.
5. **Утвердите** — результаты зафиксируются, редактирование блокируется.

### 3.6. Документы
Создавайте акты (приёма-передачи, списания), загружайте файлы, меняйте статусы
(черновик → на согласовании → утверждено) и подписывайте.

### 3.7. Отчёты
Раздел **«Отчёты»**: выберите тип и формат (Excel, PDF, CSV, JSON). Готовый
файл скачивается по кнопке.

### 3.8. Аудит
Раздел **«Аудит»**: журнал действий с фильтрами по пользователю, объекту, дате.
Доступен директору, администратору и проверяющим.

## 4. Работа со смартфона (инвентаризация)

> Упрощённый интерфейс оптимизирован для телефона. Установите приложение на
> главный экран (см. п.1).

### 4.1. Проведение инвентаризации на месте
1. Откройте **Инвентаризацию** → нужную опись.
2. Выбирайте позиции по списку (поиск по номеру/названию).
3. Отмечайте **факт** (проверено, фактическое количество, состояние).
4. При необходимости — **фотофиксация** через камеру.
5. Переходите к следующей позиции.

Режим рассчитан на сценарий «отсканировал → отметил → сфотографировал → следующий».
Ручной ввод также поддерживается.

### 4.2. Возможности телефона
- Быстрый поиск имущества по инвентарному номеру.
- Просмотр карточки и фото.
- Офлайн-доступ к интерфейсу (после первой загрузки).

---

## 5. Если что-то не работает

- Проверьте соединение и повторите попытку.
- При ошибке авторизации уточните логин/пароль у администратора.
- О технических сбоях сообщите администратору (в лог попадают все ошибки сервера).

Полная техническая документация по эксплуатации — [`docs/operations.md`](operations.md).
